## Sourcing note

Prague's own regulations come from
[`sbirkapp.gov.cz`](https://sbirkapp.gov.cz/vydavatel/48ia97h?hlavni_typ=pp) —
the *Sbírka právních předpisů územních samosprávných celků a některých
správních úřadů*, the Interior Ministry's statutory collection that
municipalities are required to publish into. Each entry was read from that
collection's own detail page for that document, and every one of those pages
names the issuing authority verbatim as `HLAVNÍ MĚSTO PRAHA`
(IČO 00064581, ID DS 48ia97h).

Checking the authority per document is not ceremony. The collection holds
every Czech municipality, so an ordinance that reads as Prague's often is not:
[`2/2019 o místním poplatku z pobytu`](https://sbirkapp.gov.cz/detail/SPPJEZKYPH7KEKIG)
looks like a Prague tourist-stay fee and is in fact Městys Kovářská's, and
repealed. It is deliberately **not** in this catalog, and it serves as the
negative test for the Prague entries (see below).

The enabling statute, Act 131/2000 Sb., is cited to the
[Chamber of Deputies' Sbírka zákonů](https://www.psp.cz/sqw/sbirka.sqw?cz=131&r=2000).
The 1784 unification of the four historic cities is cited to Wikipedia and
marked as such.

An earlier revision of this repo recorded a date "discrepancy" for Act
131/2000 — one source saying 17 May 2000, the directly-read primary source
saying 13 April 2000 — and resolved it against the former. The Chamber of
Deputies' entry shows there was nothing to resolve: **Částka 39 (17. 5. 2000)**
is the gazette issue, **účinnost od 12. 11. 2000** is when it took effect, and
13 April 2000 is when it was adopted. All three are correct and describe
different events, so the entry now carries all three. The shape of the earlier
mistake is worth naming: two sources were compared as if answering the same
question, and the one that disagreed was thrown away.

### A 200 is not evidence

Every entry carries `:ordinance/citation-probe` — the strings that must appear
in the body fetched from its URL — because on these hosts the status code
cannot tell a live citation from a dead one:

| URL shape | response for a document that does not exist |
| --- | --- |
| `praha.eu/documents/d/praha/<anything>` | `200`, 47 KB JS shell |
| `e-sbirka.gov.cz/sb/2000/<anything>` | `200`, 1 KB JS shell |

Both answer `200` for fabricated paths, returning a body of the same shape as
for a real document and carrying none of the document's text. A checker reading
only the status would call those citations healthy forever.

That is not hypothetical here. This catalog's Act 131/2000 entry used to cite
`praha.eu`'s hosted PDF — which is where its enactment date of 13 April 2000
came from, read directly on 2026-07-17. As of 2026-09-10 that URL serves the
shell above and no longer carries a character of the act. The URL is kept as
`:ordinance/prior-citation` rather than deleted, because the source rotting is
itself a fact worth recording.

### Verifying the citations

```
kbb --backend sci scripts/verify_citations.cljk             # fetch each citation, check its probes
kbb --backend sci scripts/verify_citations.cljk --control   # also prove the check discriminates
```

Exit is three-valued, so that "could not measure" never reads as "measured and
fine": `0` every citation verified, `1` at least one did not, `2` **REFUSED** —
the run could not measure at all (catalog absent, empty, or undecodable).

`--control` additionally fetches each entry's `:ordinance/citation-control`: a
real, live page that must **not** satisfy that entry's probes. For the Prague
ordinances that is the Kovářská page above — a genuine document in the same
collection from a different municipality — so a pass demonstrates the probe
discriminates on *who issued the document*, not merely on whether something
loaded. The controls are declared per entry rather than derived by mutating the
URL: an earlier version mutated the last path segment and, on `psp.cz`, changed
a parameter that server ignores, so the control fetched an equivalent page and
proved nothing.

## Scope

A **read-only reference/archive** catalog — not an Advisor⊣Governor
actuation actor. It proposes or executes nothing on the Capital City
of Prague's behalf.

Coverage is reported honestly (see `ordinance.facts/coverage`): a
municipality not in `catalog` has **no spec-basis**, full stop — never
fabricate one.
